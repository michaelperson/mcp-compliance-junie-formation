# team-frontend

Frontend Angular 22 du projet d'équipe fictif : un formulaire « Nouveau client » et la liste des clients.

```bash
npm ci
npm start            # http://localhost:4200, appels /api relayés vers le backend (proxy.conf.json)
npm run build
```

Prérequis : Node.js 22.22.3+ ou 24.15+ (exigence d'Angular CLI 22).
